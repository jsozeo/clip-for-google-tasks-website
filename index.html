Send any web selection to Google Tasks — in one click.

Right-click a passage, send it to your Google Tasks list with a deep link that scrolls back to the exact text. No account, no tracking.

Install on Chrome Read the privacy policy

How it works

1. Select & right-click

Highlight any text on any web page and choose "Clip to Google Tasks".

2. Refine the task

Edit the title, add notes, pick a due date and a target list.

3. Jump back later

Each task notes include a scroll-to-text link that opens the page exactly where the passage was.

Why this exists

Google Tasks is a great no-frills inbox for follow-ups, but capturing context from the web means copying, switching tabs, pasting, then losing the source URL. Clip for Google Tasks compresses all of that into one shortcut and adds a precise back-link using the Scroll-to-Text-Fragment specification.

Privacy by design

  • No data ever reaches ozeo's servers — clips go straight from your browser to the Google Tasks API.
  • No analytics, no cookies, no third-party trackers.
  • Open about every permission — see the privacy policy.
